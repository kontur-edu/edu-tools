# MBB — Frontmatter & status
Status: Draft (2026-09-23)

## Status line (обязательно)
Сразу после заголовка каждого документа пишем строку статуса:

`Status: <Draft|Active|Template|Superseded> (YYYY-MM-DD)`

- `Draft` — черновик, может меняться без согласования.
- `Active` — норматив, изменения согласуются.
- `Template` — шаблон (дата не обязательна).
- `Superseded` — устарел, в тексте есть ссылка на замену (используется в ADR).
- Дата — день последнего **содержательного** изменения документа. Правка опечаток дату не меняет.

Индексные файлы верхнего уровня (`.memory-bank/index.md`) строку статуса могут не иметь.

## YAML frontmatter (опционально)
Можно использовать для машиночитаемости (валидация, поиск, сборка индексов). Миграцию делаем, только если увидим реальную пользу.

Если frontmatter используется, он **заменяет** строку статуса и содержит минимум:
- `description`: что внутри;
- `purpose`: зачем читать;
- `status`: `draft` | `active` | `template` | `superseded`;
- `date`: `YYYY-MM-DD` — та же семантика, что у даты в строке статуса.
