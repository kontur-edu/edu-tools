# MBB Templates — Index
Status: Draft (2026-09-23)

- [Epic template](epic.md): шаблон описания эпика (цель, scope, фичи, зависимости, риски, definition of done). Использовать при заведении нового эпика в планах.
- [Feature template](feature.md): единственный шаблон фичи как вертикального слайса (value → deliverables → scenarios → tests → DoD). SSoT для Definition of Done фичи и формата сценариев приёмки. Использовать, чтобы каждая фича имела проверяемый сценарий и не размывалась.
- [ADR template](adr.md): шаблон записи архитектурного решения (context → decision → consequences). Использовать, когда принимается существенное решение, которое не должно быть отменено случайно.
