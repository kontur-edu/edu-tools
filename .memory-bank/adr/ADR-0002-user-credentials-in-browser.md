# ADR-0002 — Выполнение под учётными данными пользователя
Status: Active (2026-09-23)

### Context
Встроиться в официальную систему аутентификации университета не получилось. Сервис неофициальный и пишется «для себя и своих».

### Decision
Задания выполняются в браузере пользователя под его собственными учётными данными систем УрФУ (sid, куки, JWT). Пользователь сам берёт их из своей сессии и вставляет в EduTools на свой страх и риск. Учётные данные хранятся только в browser storage пользователя; собственного бэкенда нет, к системам УрФУ браузер обращается через CORS-proxy.

### Consequences
- Плюсы: не нужны серверная авторизация и хранилище секретов; каждый пользователь действует только в пределах своих прав.
- Минусы / принятые риски: неудобный вход (ручное копирование куки/токенов, инструкции); учётные данные истекают; прокси видит проходящие через него учётные данные; API систем неофициальные и могут измениться без предупреждения.
- Ограничение: появление бэкенда, хранящего учётные данные, требует нового ADR.
