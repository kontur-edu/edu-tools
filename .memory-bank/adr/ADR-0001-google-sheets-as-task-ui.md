# ADR-0001 — Google Таблицы как интерфейс заданий
Status: Active (2026-09-23)

### Context
Большинство операций, которые хочется автоматизировать, описываются одним списком строк с несколькими значениями плюс несколькими общими параметрами. Данные для заданий пользователям всё равно нужно заранее где-то собрать и согласовать, и для этого они уже используют Google Таблицы.

### Decision
Задание описывается на листе Google Таблицы: общие параметры — в паре колонок `$keys` / `$values`, строки данных — в `$`-колонках. Web-приложение принимает ссылку на лист и выполняет задание по параметру `task`.

### Consequences
- Плюсы: универсальный UI для всех заданий; новое задание не требует новых экранов — только исполнитель и описание листа; данные собираются там же, где пользователи привыкли работать; можно пользоваться формулами и вспомогательными колонками.
- Минусы: нет валидации ввода на уровне UI — ошибки листа видны только в логе (компенсируется try, см. [ADR-0003](ADR-0003-try-save-modes.md)); формат листа — неявный контракт, его нужно документировать.
- Ограничение: для каждого задания нужен Google-аккаунт с доступом к таблице.
