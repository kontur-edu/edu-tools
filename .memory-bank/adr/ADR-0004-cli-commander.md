# ADR-0004 — CLI на Commander
Status: Active (2026-09-23)

### Context
В EP-001 появляется CLI для запуска заданий без UI. Нужна библиотека разбора команд с подкомандами, опциями и генерацией `--help`.

### Decision
CLI реализуется на Commander (решение владельца проекта).

### Consequences
- Плюсы: подкоманды (`task run`, `auth check`…), опции и справка из коробки; справку можно дополнять примерами, чтобы CLI был понятен ИИ-агенту.
- Минусы: human/`--json` вывод, коды выхода и формат ошибок Commander не даёт — их реализуем сами по [CLI spec](../spec/cli/cli.md).
