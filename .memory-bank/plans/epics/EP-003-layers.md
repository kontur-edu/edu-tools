## Epic EP-003 — Слои и вертикальные слайсы
Status: `Planned`.

### Goal (user value)
Правила заданий проверяются без обращения к реальным системам, а новое задание добавляется предсказуемо: core → порты → use case → delivery. Для разработчика и ИИ-агента это меньше риска при изменениях и быстрее новые задания.

### Scope (in / out)
- In scope: интерфейсы (порты) внешних систем; выделение чистых правил (core) из исполнителей и actions; общий разбор типовых параметров задания; целевые guardrails.
- Out of scope: бэкенд и хранилище; изменение формата листов; изменение поведения заданий (только рефакторинг).

### Features (vertical slices)
- FT-0010 — Порты внешних систем — интерфейсы для БРС, ИТС, TeamProject, Partner с операциями, которые реально используются; исполнители зависят от интерфейсов. Порт источника таблицы уже появляется в FT-0015 и служит образцом.
- FT-0011 — Общий разбор параметров — `academicYear`, `semester`, `save`/`forceSave` и сообщения об ошибках параметров в одном месте вместо копий в каждом исполнителе.
- FT-0012 — Core техкарт — правила заполнения техкарты (промежуточная аттестация, нагрузки, коэффициенты) как чистый расчёт плана изменений.
- FT-0013 — Core заданий TeamProject — итерации и оценки кураторов: вычисление расхождений отдельно от вызовов API.
- FT-0014 — Core DistributeStudentsIntoTeams — сопоставление студентов, проектов и команд отдельно от вызовов API.

### Dependencies
- Internal: EP-002 FT-0006 (есть чем страховать рефакторинг); FT-0010 делается вместе с EP-002 FT-0007.

### Risks & mitigations
- Risk: рефакторинг незаметно меняет поведение → Mitigation: перед выделением core фиксировать поведение тестами и try-прогонами на тестовых листах.
- Risk: оверинжиниринг → Mitigation: порты содержат только используемые операции; слои вводятся по мере касания кода.

### Definition of done
- Все фичи имеют сценарии (setup → action → assert).
- Правила каждого задания покрыты unit-тестами без реальных систем.
- Целевые guardrails из [Architecture guardrails](../../spec/engineering/architecture-guardrails.md) переведены в действующие.
- [Layers & vertical slices](../../spec/project/layers-and-vertical-slices.md) описывает новое состояние как as-is.
