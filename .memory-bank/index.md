# Memory Bank — Index

- [Memory Bank Bible (MBB)](mbb/index.md): корневые правила ведения меморибанка (SSoT, атомарность, индексы, аннотированные ссылки, duo pattern, шаблоны). Читать перед добавлением/изменением документов. При противоречиях MBB имеет приоритет.
- [Specifications](spec/index.md): SSoT требований (WHAT): обзор, стек и структура проекта, C4, глоссарий, формат табличных заданий и каталог заданий, интеграции, инженерные стандарты, CLI. Читать, чтобы реализовывать поведение системы и писать тесты по спецификации.
- [Plans](plans/index.md): SSoT плана работ: roadmap, эпики/фичи, playbook реализации, сценарии приёмки. Читать, чтобы двигаться в правильном порядке и закрывать definition of done фич.
- [ADR](adr/index.md): SSoT решений (WHY): ключевые компромиссы и мотивация. Читать, чтобы понимать «почему так» и не отменять решения неосознанно.
