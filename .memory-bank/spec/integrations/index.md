# Integrations Index
Status: Draft (2026-09-23)

Внешние системы, с которыми работает EduTools. Все API систем УрФУ неофициальные: клиенты повторяют запросы веб-интерфейсов этих систем.

| Система | Базовый URL | Учётные данные (что вводит пользователь) | Через CORS-proxy | Для чего |
|---|---|---|---|---|
| Google | Sheets API v4 | OAuth token (кнопка «Войти через Google», scope `spreadsheets`) | нет | чтение заданий, запись результатов |
| БРС | `https://brs.urfu.ru` | `JSESSIONID` (sid) | да | дисциплины, техкарты, оценки |
| ИТС | `https://its.urfu.ru` | значение куки `ItsAuth` | да | проекты, подгруппы, запись студентов |
| TeamProject | `https://teamproject.urfu.ru/api/v2` | JWT (префикс `Bearer ` необязателен) | да | пространства, итерации, оценки кураторов |
| Partner | `https://partner.urfu.ru` | значение куки `key` (или строка cookie целиком) | да | паспорта проектов |
| Notion | Notion API | `NOTION_TOKEN` (env) | — | бот, скрипт клонирования проектов |
| Telegram | Bot API | `TELEGRAM_TOKEN` (env) | — | бот |

## Учётные данные в web
- Пользователь получает куки/токены систем УрФУ сам (инструкция по ссылке из диалога входа) и вставляет их в диалог.
- При входе стор проверяет учётные данные пробным запросом к системе. Только после успешной проверки они сохраняются в `localStorage` + `sessionStorage` и восстанавливаются при перезагрузке страницы.
- Для БРС в Node также есть вход по логину и паролю (`BrsAuth.createAsync`).

## Node
В Node запросы идут напрямую, без прокси. Google — OAuth installed-app flow: `secrets/google.json`, токены в `secrets/google-tokens.json`, политика запроса кода задаётся параметром (`ask`, `ask-if-not-saved`, `only-saved`, `always-new`).
