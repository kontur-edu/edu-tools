# System overview
Status: Draft (2026-09-24)

**EduTools** (`edu-tools`) — набор инструментов для автоматизации рутинных административных операций в информационных системах УрФУ: БРС, ИТС, TeamProject, Partner, а также для ведения базы ресурсов в Notion.

## Для кого
Преподаватели, сотрудники, поддерживающие образовательные программы, и сотрудники деканатов УрФУ. Сервис неофициальный, пишется «для себя и своих».

## Ключевая идея
Задание описывается **декларативно на листе Google Таблицы** (параметры + строки данных). Пользователь вставляет ссылку на лист в веб-приложение, приложение определяет тип задания и выполняет его, обращаясь к внешним системам от имени пользователя.

## Ключевые свойства
- **Try / Save.** Любое задание можно прогнать «вхолостую» (try): всё читается, сравнивается и логируется, но изменения во внешние системы не пишутся. Save — то же самое с записью.
- **Сходимость к желаемому состоянию.** Исполнители сравнивают текущее состояние во внешней системе с заданным в таблице и меняют только расхождения. Повторный запуск безопасен.
- **Прозрачный лог.** Результат — текстовый лог со статусами-эмодзи (🟢 изменено, 🟡 без изменений/пропущено, 🔴 ошибка по элементу, 🟩/🟥 итог по группе).
- **Без собственного бэкенда и хранилища.** Всё выполняется в браузере пользователя под его собственными учётными данными; креды хранятся только в browser storage. Запросы к системам УрФУ идут через CORS-proxy.

## Поставляемые части
- **Web app** — основной продукт (https://edu-tools.fiit-urfu-cloud.ru): вход в Google и внешние системы, загрузка и выполнение табличных заданий.
- **Telegram bot** — сохраняет присланный текст как страницу в базе ресурсов Notion. В перспективе заменяется web-приложением или PWA.
- **CORS-proxy** — прокси для обращения браузера к API УрФУ.
- **CLI** (`src/cli/`) — команды для разработчика и ИИ-агента с human/`--json` выводом ([CLI spec](../cli/cli.md)); пока проверка учётных данных и вход в Google. Запуск заданий с параметрами в коде — пока в разовых скриптах `src/legacyScripts.ts`.
- **brs-extensions** — не часть продукта: отдельное старое веб-приложение для переноса баллов из Google Таблиц в БРС. Хранится как референс; его функциональность нужно перенести в edu-tools, сам код не развивается.
