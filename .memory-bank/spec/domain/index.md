# Domain Index
Status: Draft (2026-09-23)

Доменные правила: что система делает с данными пользователя и внешних систем.

- [Table task format](table-task-format.md): разметка листа Google Таблицы как задания (параметры, колонки, пространства имён, типы значений, try/save). Читать перед подготовкой листа или изменением `TableTaskReader`.
- [Table sources](table-sources.md): источники листа (Google Таблица, CSV), модули CSV codec / parser / source / converter, формат CSV и правила конвертации. Читать перед изменением чтения/записи листа или подготовкой CSV-фикстур.
- [Task catalog](tasks/index.md): поддерживаемые задания, их параметры, колонки и правила. Читать перед изменением или добавлением исполнителя задания.
- [Telegram bot](telegram-bot.md): сохранение сообщений в базу ресурсов Notion. Читать перед изменением бота.
