# Task: SendCuratorMarks
Status: Draft (2026-09-23)

Выставляет оценки куратора студентам за итерацию в TeamProject.

## Параметры
- `academicYear`, `semester` — обязательные.
- `iterationNumber` — обязательный, номер итерации (с 1, по порядку в пространстве).
- `save`.

## Колонки
- `$student`, `$curator`, `$iteration<N>` (оценка за итерацию N, целое) — обязательные.
- Проект: `$projectUrl` или `$projectName` + `$projectInstanceNumber` — см. [Workspace identification](workspace-identification.md).
- `$skip` — непустое значение исключает строку.

## Поведение
Для каждого найденного рабочего пространства:
1. Берётся N-я итерация и текущие оценки её студентов.
2. Студент ищется по началу полного имени (нормализованно). Не найден → 🟡.
3. Оценка не число → строка игнорируется (🟡). Оценка отличается → выставляется (🟢 / 🔴 при ошибке). Совпадает → 🟡.

Проверки полноты:
- по пространству: студенты проекта без оценки в таблице → 🔴 и итог 🟥;
- в итогах: строки с указанным проектом, для которых проект не найден → 🔴; строки без проекта → 🟡.

## События
Модель, статусы и рендер — [Execution events](execution-events.md); читать перед изменением сообщений лога. Scope — студент из `$student` (для студентов проекта без строки в таблице — полное имя из TeamProject) или проект `Название (номер)`; `details` — `mark`, `currentScore`.
- оценка выставлена → `changed`; уже такая → `unchanged`;
- студент не найден в указанном проекте, оценка не число, строка без проекта → `skipped`;
- оценка не выставлена, студент проекта без оценки, проект строки не найден → `error`;
- у проекта нет N-й итерации / оценок / списка студентов → `error` со `stopped`;
- итоги по проекту и по заданию (🟩 / 🟨 / 🟥) → `verdict`.
