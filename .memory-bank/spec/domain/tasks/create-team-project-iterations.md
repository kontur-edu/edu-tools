# Task: CreateTeamProjectIterations
Status: Draft (2026-09-23)

Создаёт и обновляет итерации в рабочих пространствах проектов TeamProject.

## Параметры
- `academicYear`, `semester` — обязательные.
- `save`.

## Колонки
- Проекты (основные строки): `$projectUrl` или `$projectName` + `$projectInstanceNumber` — см. [Workspace identification](workspace-identification.md).
- Итерации (пространство имён `iteration`): `$iteration.name`, `$iteration.startDate`, `$iteration.endDate`. Даты в формате `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`.

## Поведение
Для каждого найденного активного рабочего пространства:
1. Существующие итерации, название которых совпадает с итерацией из таблицы, получают даты из таблицы, если те отличаются (🟢), иначе 🟡.
2. Если итераций в пространстве меньше, чем в таблице, недостающие добавляются **по позиции**: начиная с номера, равного числу существующих.

## События
Модель, статусы и рендер — [Execution events](execution-events.md); читать перед изменением сообщений лога. Scope — проект (`Название (номер)`) или итерация (`Название (номер) / Итерация`); `details` — `from`, `to`.
- добавлена / обновлена итерация → `changed`; даты совпадают → `unchanged`;
- итерация из списка пространства не найдена → `error`;
- у пространства не удалось получить итерации → `verdict failed` (итог стадии, проект пропускается; в `counts` не входит);
- «Iterations are ready» → `verdict ok`.
