# Task: DistributeStudentsIntoTeams
Status: Draft (2026-09-23)

Записывает студентов в команды (подгруппы) проектов в ИТС.

## Параметры
- `academicYear`, `semester`, `studyYear` — обязательные.
- `save`.

## Колонки (все обязательные, иначе строка пропускается)
`$fio`, `$group`, `$projectName`, `$projectInstanceNumber` (номер команды).

## Поведение
1. Загружается список проектов ИТС за (academicYear, semester, studyYear).
2. Проект строки ищется по названию (нормализованное сравнение). Не найден → 🔴.
3. Команда — подгруппа проекта с индексом `projectInstanceNumber`. Не найдена → 🔴.
4. Студент в подгруппе ищется по началу ФИО (нормализованно) и точному совпадению группы.
5. Уже записан → 🟡; иначе записывается в первую подгруппу команды (🟢, при ошибке 🔴).
6. После записи (save) состав команды перечитывается, чтобы проверить, что запись применилась.

## События
Модель, статусы и рендер — [Execution events](execution-events.md); читать перед изменением сообщений лога. Scope — студент `ФИО (группа)`.
- записан (в try — будет записан) → `changed`; уже записан → `unchanged`;
- не найден проект, команда или студент в ИТС, ошибка записи → `error`.
