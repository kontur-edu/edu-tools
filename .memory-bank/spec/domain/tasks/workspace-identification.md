# Workspace identification (TeamProject)
Status: Draft (2026-09-23)

Как строка таблицы указывает на рабочее пространство проекта в TeamProject.

- `$projectUrl` вида `https://teamproject.urfu.ru/#/<guid>` — точная идентификация по id.
- Иначе `$projectName` + `$projectInstanceNumber` — ключ `"<название> (<номер>)"`, сравнивается с названием и номером экземпляра пространства.
- Если нет ни URL, ни пары «название + номер», строка считается строкой без проекта.

Кандидаты — все **активные** пространства за (academicYear, semester), загружаемые постранично по 100.
