# Telegram bot: ресурсы в Notion
Status: Draft (2026-09-23)

Бот сохраняет присланный текст как страницу в базе ресурсов Notion (`NOTION_RESOURCES_DB`).

**Перспектива:** бот — часть edu-tools, но его планируется разобрать: сценарий переедет в web-приложение или PWA (см. [Roadmap](../../plans/roadmap.md)). Новую функциональность в бота не добавляем.

## Поведение
- `/start` — приветствие.
- Текстовое сообщение:
  - пустое → «Текст не может быть пустым!»;
  - иначе форматирование Telegram конвертируется в HTML, **первая строка** становится заголовком страницы, **остальное** — её содержимым (HTML → Markdown → блоки Notion);
  - в ответ бот присылает заголовок и ссылку на созданную страницу;
  - при ошибке — «Что-то пошло не так...».
- Пока идёт обработка, бот показывает индикатор загрузки.

## Развёртывание
Yandex Cloud Function `fiit-tools-bot` (webhook, `bot.cloudHandler`); запрос без тела возвращает `pong`. Webhook регистрируется `npm run bot-register`.
