# Table task format
Status: Draft (2026-09-24)

Табличное задание (table task) — лист Google Таблицы, который описывает, что сделать. Это основной пользовательский интерфейс системы.

## Источник
- **Google Таблица** (web и Node): пользователь вставляет URL вида `https://docs.google.com/spreadsheets/d/<spreadsheetId>/edit#gid=<sheetId>` (или `?gid=`). `gid` обязателен: по нему определяется имя листа.
- **CSV-файл** (target, только Node/CLI и тесты): тот же лист в виде CSV, разметка идентична. Подробности — в [Table sources](table-sources.md).

## Разметка листа
- **Строка 1 — заголовок.** В задании участвуют только колонки, заголовок которых начинается с `$`. Остальные колонки игнорируются, в них можно держать вспомогательные данные и формулы.
- **Имена нормализуются:** регистр, пробелы, `_`, `-`, `$` не важны, `ё` = `е` (`$Project Name` ≡ `$projectname`).
- **Параметры:** пара колонок `$keys` / `$values`. Со строки 2 вниз — пары «ключ → значение» до первой пустой ячейки ключа. Читаются только первые 100 строк листа.
- **Параметр `task`** — имя типа задания (без учёта регистра). Без него лист не считается заданием.
- **Данные:** остальные `$`-колонки. Каждая строка ниже заголовка — запись. Пустые строки (все значения пустые) пропускаются.
- **Пространства имён:** колонка `$ns.field` кладёт значение в отдельный набор строк `ns` (например, `$iteration.name`). Так на одном листе описываются две независимые таблицы.
- **Дополнительные колонки** (target, [FT-0005](../../plans/features/FT-0005-put-marks-to-brs-task.md)): колонки с заголовком на `$$` — упорядоченный набор, смысл которого определяет задание; повторы разрешены, пространств имён нет. Правила — в [ADR-0006](../../adr/ADR-0006-extra-columns.md).

## Типы значений
- строка;
- целое число;
- список целых через запятую (`1, 2, 3`);
- bool: `true`/`false` или число (≠ 0 → true).
Если значение не распознано или ячейка пустая, оно считается отсутствующим (пустая ячейка — независимо от того, где она стоит в строке). Значения обрезаются по краям пробелов.

## Общие параметры
- `save` (bool, по умолчанию false) — писать ли изменения. В web переопределяется кнопкой: try → false, save → true.
- `academicYear` — учебный год в виде `2024/2025`, используется первый год.
- `semester` — `fall` → 1, `spring` → 2.

## Обработка ошибок
- Не хватает обязательного параметра → в лог пишется `- <param> required❗`, задание не выполняется.
- Строка без обязательных полей пропускается; в лог пишется, сколько строк распознано из общего числа.
