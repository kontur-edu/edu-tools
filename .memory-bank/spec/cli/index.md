CLI пока нет — документы раздела описывают целевое состояние (EP-001).

- [CLI spec](cli.md) — принципы, формат вывода (human/`--json`) и схема результата задания. Читать, чтобы автоматизировать сценарии без UI и чтобы ИИ-агент мог управлять системой через CLI.
- [Command catalog](command-catalog.md) — 1:1 соответствие «команда → исполнитель», учётные данные и признак записи. Читать, чтобы CLI и web использовали один и тот же движок и не расходились по поведению.
