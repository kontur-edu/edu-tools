# C4 L1 — System Context
Status: Draft (2026-09-23)

## System
**EduTools** — инструменты автоматизации административных операций в системах УрФУ. Пользователь описывает задание на листе Google Таблицы, EduTools выполняет его во внешних системах от имени пользователя (try / save).

## People (actors)
- **Администратор ОП** (преподаватель, сотрудник, поддерживающий образовательные программы, сотрудник деканата) — работает через web-приложение: входит в Google и нужные системы УрФУ, запускает табличные задания.
- **Разработчик** — запускает задания и разовые операции из Node-скриптов (`src/main.ts`), деплоит части системы.
- **Пользователь Telegram-бота** — присылает боту текст, чтобы сохранить его как ресурс в Notion.

## External systems
- **Google** (OAuth + Sheets API v4) — хранение заданий и запись результатов (например, экспорт техкарт).
- **БРС** (`brs.urfu.ru`) — балльно-рейтинговая система: дисциплины, техкарты, оценки.
- **ИТС** (`its.urfu.ru`) — проекты, подгруппы (команды) и запись студентов в них.
- **TeamProject** (`teamproject.urfu.ru`) — рабочие пространства проектов, итерации, оценки кураторов. Токен выпускается Keycloak УрФУ (`keys.urfu.ru`).
- **Partner** (`partner.urfu.ru`) — паспорта проектов от партнёров.
- **Notion** — база ресурсов (бот) и база проектов (скрипт клонирования проектов из Partner).
- **Telegram Bot API** — канал бота.
- **Yandex Cloud** — хостинг: Object Storage (web), Cloud Functions (бот), Serverless Containers (CORS-proxy).
