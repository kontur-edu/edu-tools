# Spec Index — edu-tools
Status: Draft (2026-09-23)

Этот раздел — **SSoT по требованиям** (WHAT). Решения «почему так» живут в `../adr/`.

- [Project](project/index.md) — что это за система, стек, структура репозитория, слои и vertical slices. Читать, чтобы держать фокус и не расползаться.
- [Glossary](glossary.md) — словарь терминов (системы УрФУ, табличные задания, техкарты, проекты/команды/итерации). Читать, чтобы одинаково понимать термины в коде, таблицах и документах.
- [C4](c4/index.md) — L1/L2/L3 описания системы и разбиение на контейнеры/компоненты. Читать, чтобы понимать, где что выполняется и куда класть код.
- [Engineering](engineering/index.md) — стандарты кодирования/архитектурных границ/документации. Читать, чтобы код был однообразным.
- [Domain](domain/index.md) — формат табличного задания, каталог заданий и их правила, Telegram bot. Читать, чтобы реализовывать и менять исполнители заданий.
- [Integrations](integrations/index.md) — внешние системы, учётные данные, CORS-proxy. Читать при работе с API внешних систем и авторизацией.
- [CLI](cli/index.md) — CLI контракт и команды (human+json). Читать, чтобы агент/разработчик мог воспроизводить сценарии без UI.
